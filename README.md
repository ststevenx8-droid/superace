# ST WIN ACE - Premium Arcade Slot Demo

ST WIN ACE is a 5x3 arcade reel simulation game built purely using Vanilla JavaScript, HTML5, CSS3, and Firebase Realtime Database.

## Features
- **Original Artwork & Vector Symbols**: Crown, Star, Coin, Ruby, and Royal Cards built in native SVG.
- **Dynamic 5-Reel Physics**: Staggered column stops and CSS motion blur.
- **Bonus System**: 3 Golden Stars grant 5 Free Demo Spins with no credit deduction.
- **Zero-Asset Audio Engine**: Built-in Web Audio API synthesizer for spins, reel stops, and jackpot alerts.
- **Demo Wallet & Credit Requests**: Allows requesting virtual coins stored under Firebase `demoCreditRequests`.
- **Informational bKash Card**: One-click number copy interface with zero deposit/withdrawal integration.

## How to Run Locally
1. Clone or download this directory.
2. Serve with any local HTTP server (such as VS Code Live Server or `python3 -m http.server 8000`).
3. Open `http://localhost:8000` in your browser.
